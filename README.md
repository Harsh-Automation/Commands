# Playwright, Selenium & Git Cheat Sheet

This package contains the complete stand-alone website for Playwright, Selenium, and Git commands reference.

## Usage
1. Open `index.html` directly in any modern web browser.
2. No local server or build tools required!

## Features
- Toggle between Playwright, Selenium, and Git tabs
- Search filter across commands
- Category filtering
- One-click copy code snippets
- Dark and Light mode switcher
