Playwright Automation

Modern end-to-end testing for web apps. Reliable, fast, and multi-browser.

31 Commands
Installation & Setup

Initialize Playwright

Sets up a new Playwright project with config, sample tests, and GitHub Actions workflow.

npm init playwright@latest
Installation & Setup

Install Browsers

Downloads required browser binaries (Chromium, Firefox, WebKit).

npx playwright install
Installation & Setup

Install Specific Browser

Installs only specified browser engine.

npx playwright install chromium
Installation & Setup

Install Dependencies

Installs system dependencies required for headless browsers on Linux.

npx playwright install-deps
Running Tests

Run All Tests

Executes all tests in headless mode across configured browsers.

npx playwright test
Running Tests

Run in Headed Mode

Runs tests with visible browser UI.

npx playwright test --headed
Running Tests

Run Specific Test File

Executes test file directly.

npx playwright test tests/login.spec.ts
Running Tests

Run UI Mode

Opens interactive UI Mode with time-travel debugging, watch mode, and locator generator.

npx playwright test --ui
Running Tests

Debug Mode

Launches Playwright Inspector to step through tests line by line.

npx playwright test --debug
Running Tests

Show HTML Report

Opens the generated HTML test execution report in browser.

npx playwright show-report
Locators & Selectors

By Role

Locates by ARIA role and accessible name (Recommended).

page.getByRole('button', { name: 'Submit' })
Locators & Selectors

By Text

Locates element by visible text content.

page.getByText('Welcome back')
Locators & Selectors

By Label

Locates form control by associated label text.

page.getByLabel('Username')
Locators & Selectors

By Placeholder

Locates input by placeholder text.

page.getByPlaceholder('Enter password')
Locators & Selectors

By Test ID

Locates element by data-testid attribute.

page.getByTestId('submit-btn')
Locators & Selectors

CSS / XPath Fallback

Locates elements using standard CSS selectors or XPath.

page.locator('css=button.btn-primary')
